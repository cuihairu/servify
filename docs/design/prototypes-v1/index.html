风格结论（从参考例提炼）

参考 Crisp 的客服产品体验与交互模式（仅提炼模式，不抄代码与资产），结合设计系统方法生成器多轮对标，收敛为：

  • Flat Design + 一层卡片阴影：无重质感、无拟物；层级靠阴影与描边表达，不靠装饰。
  • Inbox blue 主色：light #2563eb / dark #3b82f6（暗版提档保 4.5:1 对比度），专业的信任感蓝，同行业客服 SaaS 主流色相。
  • Inter 字体栈：数字 tabular-nums；中文回退 PingFang SC / Microsoft YaHei / Noto Sans SC。
  • 圆角语言：沿用现有 widget token——面板 16 / 气泡 12 / 输入 20（胶囊）/ 控件 8。
红线：零渐变。全站（含 header、按钮、悬浮球、图表）只用纯色；亮度分层代替渐变分层。所有原型已按此约束产出，examples/theme.json 中的 headerBg: linear-gradient(...) 为历史遗留，实现阶段一并去除。

从参考例借鉴的交互模式（原型已落位）

结论：8 条全部为可参考级——均为参考例验证过的成熟模式，且与竞品调研 《竞品调研》§四结论一致（聊天体验是同质化标配，差异点在 AI 首答形态与转人工顺滑度），故全部保留进原型；对应实现验收点是 todo C1-2（主题定制）与 C1-3（两风格真机验证），实现阶段按下列各项逐条对屏验收。

  1. 悬浮球多态：收起 / 未读徽标 / 展开（240ms spring，自右下角 scale+fade）→ widget-fab
  2. 日期分隔行 + 已读回执（双勾） → widget-chat
  3. AI 首答带「AI 徽标 + 知识库来源引用（citation chip）」 → widget-chat / embed-*
  4. 快捷回复 chips + 转人工入口常驻 → 全部聊天屏
  5. AI → 人工无缝转接：系统行「已为您转接人工 · 李晴」，坐席头像切换 → 全部聊天屏
  6. 移动端底部 sheet + 把手 + 安全区 → widget-mobile / embed-light 右侧变体
  7. 品牌色注入：客户站覆盖 5 个语义 token 即整体换肤（青屿云 teal 演示，暗版自动提档）→ embed-light / embed-dark
  8. 暗色自适应：跟随系统 + 远程主题强制档 → 全部屏
