# Documentation-Source Consistency Audit (2026-10-13)

- **Audit target**: all public documentation surfaces of the servify repository (README.md, README.zh.md, ARCHITECTURE.md, docs/**, design documents) + public storefront (GitHub About/README first paragraph)
- **Execution standard**: `~/workspaces/standards/文档与源码一致性审计规范.md` (three difference classes + six steps)
- **Evidence convention**: every claim carries a `file:line`; before asserting "not implemented", confirm the search path exists (an empty grep ≠ not implemented); self-congratulatory completion reports and `- [x]` checkmarks are both treated as claims to audit
- **Fix principle**: code is the authority; claims ahead of code are deleted or marked "not implemented/planned"; code is never changed to accommodate documentation
