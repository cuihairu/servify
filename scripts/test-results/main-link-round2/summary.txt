主链路人工运行验证第二轮 复跑留证（2026-09-27）
=============================================================
环境：redis=系统实例 PONG；postgres=本机仅 postgresql-client-18（无服务端
二进制 initdb/postgres，无 sudo 装包），按任务口径回退 sqlite
（DB_DRIVER=sqlite DB_DSN=.cache/main-link-r2/servify.db，服务启动 AutoMigrate）。
服务：SERVIFY_JWT_SECRET=dev-secret go -C apps/server run ./cmd/server
      --host 127.0.0.1 --port 18080（全新空库后种子数据，证据内 ID 为确定性小值）。
限流：全局 60rpm/burst10（config.yml）；种子脚本突发后以 sleep 回填令牌桶，
不用 X-API-Key 白名单键——该键会令 AuthMiddleware 走 service-principal 分支
（platform/auth gin_middleware.go:41）短路 Bearer JWT 致 401，两中间件语义冲突。
自动派单观察（真实行为）：种子置 agent1-3 online 后，10 张工单创建即被自动
路由派给客服1（id=2），dashboard assigned_tickets=10/open_tickets=0；
故第 12 步对账口径为「改派客服2(id=3) 前后 agent_id 2→3」。
